Method

This computes the optimal average gain using Howard's policy iteration, which is equivalent to the LP formulation under standard conditions. It returns:

  • g*: optimal long-run average reward
  • V(s): average gain per start state (equals g* in communicating MDPs)
  • h(s): bias (relative value) vector
  • d(s): stationary distribution under π*
